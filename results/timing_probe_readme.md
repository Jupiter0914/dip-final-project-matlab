# 开发样本计时检查

原始输入为固定开发品种的官方 trainval 蒙版 Bengal_187，256字节，最多8轮，轮首上限200 ms。每个独立 MATLAB 进程按正、反、正、反顺序测试六种方法，共24次。每次方法调用从内存中的同一原图独立开始。进程分别使用默认线程与启动参数 `-singleCompThread`。这些数据用于解释首调用与仪器开销；正式确认有独立的三次 MATLAB 进程和独立的预热。

| 实测项目 | 默认24线程 | 单线程 |
|---|---:|---:|
| 外部启动至进入探针（ms） | 5018.439 | 5377.705 |
| 原图读取与哈希（ms） | 275.818 | 190.689 |
| bwconncomp 第一次/紧随第二次（ms） | 68.548 / 1.455 | 27.949 / 1.390 |
| seed第1、2、3、4遍的实收时刻（ms） | 308.450 / 38.097 / 36.045 / 33.737 | 264.094 / 42.811 / 45.543 / 47.321 |
| 300次 PM31 pack 中位数（ms） | 0.0138 | 0.0126 |
| 调用至接收函数首行中位数（ms） | 0.0007 | 0.0006 |
| 空接收器往返中位数（ms） | 0.0012 | 0.0011 |

第一次编码同时包括JIT、函数首次加载和缓存状态，不宜把初次与后续调用的耗时差全部归给JIT。每个线程条件只启动一次，不能从这两次启动推出线程数的普适影响。完整接收器保存字节和事件；这里的仪器往返只测接收入口读钟，含 `toc` 的测量开销。每次 pack 的输入来自实际开发编码，将输出与同一份字节逐项校验。文件的前缀 `timing_probe_default` 和 `timing_probe_single` 对应两进程，`environment`、`encoders` 和 `callback` 分别是环境及首次工具箱读数、逐次实际编码记录与300行微测量。
