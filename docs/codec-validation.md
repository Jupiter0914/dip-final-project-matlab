# PM31 编解码与像素验证

在 R2024a 实际执行 `runtests('tests/testCodec.m')`，五个测试函数均通过。每项的独立耗时与通过标志见 [codec-tests.csv](codec-tests.csv)。

| 输入或攻击面 | 比较对象 | MATLAB 结果 |
|---|---|---|
| 512 种 3×3 掩模和 8 个具名边界、孔、岛和部件夹具 | 附尺寸的输入像素摘要及固定的 PM31 字节摘要 | 520 个逐像素无损、520 个文件逐字节一致 |
| 120 组两点线迹及随机边、多边形和奇偶填充 | OpenCV 5.0 LINE_8 在完整四倍画布上产生的原中心像素 | 120 个逐像素相同 |
| 4 张已分配的官方 trainval 开发源，每图三个字节档 | 12 个历史文件本身及独立保存的参考解码像素 | 历史文件解码全部相同，重新序列化字节全部相同 |
| 当前 36 张允许开发的 Oxford 输入 | 每个源的原始字节、原尺寸规范像素及无损轮廓的 PM31 摘要 | 36 张核验通过，逐像素无损，36 份完整轮廓文件字节一致 |
| 截断、尾字节、坏魔数、无效尺寸、父号、点数、坐标、交叉环，超出画布和非二值输入 | 指定异常类型 | 全部拒绝 |

[固定夹具](../data/compat)给出可直接比较的输入、文件和像素摘要。analytic.csv 和 dev_dense.csv 分别覆盖合成蒙版和开发标注。legacy.csv 登记 12 份 PM31，其同名 PNG 保存预期解码像素。raster.json 保存固定种子 77133 的点列和逐位参考像素。

`readFrozenMask` 读取原始标注，核实 SHA-256，然后比较原尺寸、规范像素摘要。Oxford 取 PNG 原索引 1，LEMS 取首行、首列、末列三者中位数的中位数为背景。`pixelHash` 在行序连续位流前加小端高宽，首像素占首字节最高位。消息摘要使用 MATLAB 自带 JVM 的 SHA-256 实现。

`extractRings` 在补边采样格上用 16 种方格配置重建 0.25 等值线。对角鞍点以高于 0.25 的中心连接前景。以图像向下为纵坐标正向，外环有向面积为正。取顶部最左点，外环从它的前一顶点起步，孔从该点起步，之后删除共线点。这一步影响后续最远点和并列决策。

`rasterRing` 用带 16 位小数的横向斜率和成对扫描交点进行内部填充，另合入包含端点的八连通整数边线。保留高分辨率坐标，只计算扩展画布中会被读取的原像素中心。双点删除代理可以绘线，但文件编码要求每环至少三点。PM31 坐标 (4,4) 对应 MATLAB 掩模的 (1,1)。`decodePM31` 仅依据字节解析、检验连续几何与父关系，然后逐环 XOR。互操作性结论限定于协议与这里实际核验的样例。
