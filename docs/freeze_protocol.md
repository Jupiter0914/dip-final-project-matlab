# 基础实验的样本、预算与接收时限

基础实验在预先登记的 200 个 Oxford 来源和 100 个外部 LEMS 来源上进行。从原始标注重新编码，按来源配对比较。另一次独立确认的样本和主要终点见 [精确评价实验方案](optimization_plan.md)。

开发白名单为 data/manifests/dev.csv。所有方法各自从原尺寸二值数组起步，计时含提取、初始化、搜索、验证、序列化及同步接收器入内首条时钟读数。整文件已接收才算交付。实际写盘与离线评价单列。每轮开始前检查 200 ms 上限，至多 8 轮。空图10 B，每环至少3点。共同成功的实际码长相同才比较质量。传统几何基线稳定按环号和原顶点下标择并列，保护活动顶点的扫过三角形，在目标点数执行共同验收。

主检验 Oxford 多环、256 B、实收 100 ms 的 within_full 减 cross 的错分差。五法在全部300源，128/512 B 与 exact 依配置中的48源。每次编码同时观察 100/200 ms，共 12,168 个独立调用。三个新 MATLAB 进程，单线程、串行，各两次，顺序使用固定盐和六次轮换。源内先按有效重复、再按有效会话平均，最后源间等权。10,000次来源级百分位重抽，twister 40121。三会话均正、留一源均正、平均差区间下限为正、全 Oxford 交付差区间下限至少 −0.02 才支持稳定增量。外部另给类别簇与留类；正负结果同样归档。失败与截止前未收到采用实际状态保留，质量项为空。预先不设绝对及时率合格线。

结构代价在全部396源/预算上离线重建。首会话首次重复 exact 子集的全部已交付 cross/exact 状态按二进制去重，再核查同一候选池；包含共同起点。离线结果不能倒算至截止时。实时编码只读取内存中本次源，不读历史输出。
