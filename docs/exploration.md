# 早期研究复算

这些开发试验读取 `data/manifests/dev.csv` 指定的 36 张官方 Oxford trainval 图。早期结果进入 `results/exploration/`。基础实验的正式配对、区间与插图只读取独立的正式接收事件。

## 单圈导出

单圈试验处理最大外轮廓填出的原尺寸蒙版。按连续多边形面积选择外圈，其余小部件会被删去，孔会被填上。逐次记录列出此过程新增和删除的像素。几何起点沿固定切点的轮廓进行平方直线误差 DP，网格包含 RDP 的 K 点和均匀采样点。每次局部扫描使用八方向、半径 8/4/2/1/4/2/1 和正反交替的顶点顺序。XOR、IoU 与 BF2 保护的试验共用扫描规则。BF2 比较在欧氏两像素圆盘下计算。文件魔数为 POL1，长度为 10+4K，以原生整数顶点和八连通边线解码。

选取预先登记的 pomeranian_10、pug_127、British_Shorthair_187，分别用 16 和 32 点运行 RDP、网格 DP、全点 DP、几何微调、直接 XOR、同搜索 IoU、从 50 点顺序按 IoU 删除、几何后 XOR 及带 BF2 下限的几何后 XOR，共 54 次独立导出。保留每个实际 POL1、逐次码长、错误像素、BF1/2/3、接受和拒绝次数。该子集用于研究单圈轮廓的误差。

## 作者 UPF-PSO

复算使用 MathWorks File Exchange 1.0.0 作者发布包，70,808 字节，SHA-256 为 `67c9a9f527142f8e2e5f4cec7a8a2724930059ecb876cc678095dbc3a868c1bc`。原版求解器的作者为 Costas Panagiotakis（2024）。已核对包内 license.txt，其中列明随源代码保留版权、条件和免责声明以及署名使用条件。项目只发布 MATLAB 调用和真实数值结果；原包可由审核者自行下载。`explorePSO` 查找 `data/upf-author.zip`，缺失时从下列原始地址下载，校验 SHA-256 后才解压到 MATLAB 临时目录。成功、异常结束均移除临时路径和解包目录，不向仓库添加作者的 .m 文件。[MathWorks 原版下载](https://addons.mathworks.com/downloads/9b/9bf0e77b-720e-422d-a51d-beee4b9483fe/1.0.0/unconstrained_polygonal_fitting-1.0.0.zip)

同三源分别使用 K=8/16/32 和种子 1703、2909、4231，保留所有 27 次结果。作者函数取单圈填充掩模、区域质心与面积，原生浮点坐标、IoU 和 Dice 单独记录。从 MATLAB 1 基顶点以原半入舍入规则转换、裁回图像并编码 POL1，记录被裁顶点数。该批未纳入 Fish-a100 作者示例，其来源超出本轮开发图范围。

## 完整蒙版与候选规则

36 张 trainval 上对每幅图重新运行 256 B、固定两轮的六个对照。对照涵盖旧版圈内短表、全组合禁三角圈内、充分圈内、旧跨环短表、全组合禁三角跨环和充分跨环。每个方法独立生成合法起点。逐源记录合法配对、入选提案、未达到 24 对的轮数、接受与跨圈/三角动作、搜索结束误差及 PM31 文件。独立运行两轮后获得的质量不能用作 100/200 ms 的及时交付数据。本表覆盖全部 36 张获准开发源，并登记实际环数。

分配诊断覆盖同 36 源、128/256/512 B，至少八圈的源另查 1024 B。同时核对周长分配、最低可加误差解、有限池首个结构合法解和池内真实 XOR 最优解。每个池成员保留逐圈代价和整图 XOR；两种排序的平局也计入逐对排序一致性。触发修复时比较直接按代价次序检查与“其余圈保持高精度”的局部上下文提示，两者均限制为 64 次结构询问。排序使用每个后缀和的前 64 个分配，按代价和字典序决定先后。上下文排除只用于提示，回退时仍在原未屏蔽的分配集合中查找。


## 运行与原始输出

由仓库根目录启动单个 MATLAB 进程。R2024a、Image Processing Toolbox、开发清单及其 36 个通过双哈希校验的原始输入为前提。作者数据包可提前置于 data 下，或由 MATLAB 联网下载。为避免影响正式计时，把此入口安排在最后一个正式会话退出之后执行。

```powershell
matlab -batch "addpath('scripts'); run_exploration('all')"
```

也可以指定 single、pso、controls 或 allocation 独立重建相应输出。poly02_trials.csv、pso_trials.csv、within_candidate_controls.csv、allocation.csv、allocation_pool.csv 和 repair_checks.csv 记录实测观察。verify 模式从每一份实际文件重新解码并生成 audit_summary.json 和两轮配对表。开发烟测首次发生在空结构数组追加字段的位置；已替换为带完整字段的空模板，完整重测使用修正入口。
