# 快速评价的依赖和等价条件

参考入口来自提交 `8b5835a415f1224076e318229f829b0856d5266e` 的 `src/evaluation/measureEncoding.m`。第 1 轮生产入口为 `performance/kernel/efMeasure.m`，四种方法每次均独立从原尺寸二值图重新准备输入、检查无损回填、构造种子并同步提交完整 PM31。该轮改变逐环候选的重复计算，保留原有的整图计算和接受判据。程序的静态论证和实测轨迹核对分别提供证据。

## 单项的依赖

设当前第 (i) 个环的有序顶点序列为 P，原始稠密环为 H，参考孤环蒙版为 R。活动环的图层和误差分别为 `rasterRing(shape,P)` 与 `nnz(layer~=R)`。删除 P 的第 j 点，或在当前第 j 条边后插入某一源点，都在相同的原尺寸坐标系上独立调用原光栅化函数。以两种误差的差计算代理代价。每种代理只读取图幅、H、R、P 及当前孤环图层。其他环的移动不会改变这些输入。

原稠密环和参考图层在一次编码调用内固定。环号不变且 P 的数值、形状、顺序相同，原点在 H 中的下标、每条边所夹的源弧、最远点及中点、三角环删点后的两点线迹，以及每个单删和单插的代价都相同。最远距离用原有线段投影和首个最大值，索引中点遵从原来的整除取整。首次计算时保持原枚举顺序和数据类型，保存两个实际候选表以及源点下标。

| 生命周期 | 实际实现 |
|---|---|
| 新编码调用 | 在本次种子回调后初始化空缓存。没有全局、persistent 或跨调用对象 |
| 首次访问某圈 | 按该圈当前完整有序点列重建其单项候选、下标及孤环误差 |
| 本圈删插获准 | 清除该圈条目，下一轮重新计算。即使点数未变，其顶点、边和源弧也可能改变 |
| 跨圈删插获准 | 清除供体和接收体。下一轮两个环的分数和可供操作的位置分别重建 |
| 其他圈未变 | 重新核对完整有序点列后复用已有条目。误差或边排名与其他圈的组合仍会重新计算 |
| 无操作获准或计时停止 | 本次调用结束，缓存随局部变量释放 |

## 从单项到真实交付

1. 每轮按原环号及顶点枚举次序拼接单项表，重建全局合法组合。同圈排除删点处的两条相邻边，三角环可在本圈对边替点，跨圈供体须至少有四点。同一供点的接收序列按既定键排序，取各自前 24 的并集，再按原七列完整键选择全局前 24。被一个供点的第 24 个组合严格排在后面的项，在全局也不能排进前 24。完整键含坐标和操作位置，决定所有平局次序。
2. 对每个入选提案，用原 `replaceVertex` 在操作前的下标上构造最终点列。变动环按原顺序逐一调用 `rasterRing`，用真实最终孤环误差更新原可加总和。同圈删插只渲染最终的一个环。
3. 保留可加总误差严格下降的项，按最终代价和原提案顺序验证。参考实现普通可加分支构造的 `whole` 仅在 `exact` 和离线诊断分支计算候选整图预测时使用。第 1 轮生产范围内省去了这一次临时的异或合成。后面的整图验证独立调用原 `validateState`，它会对全部环重画并进行奇偶合成，再核对真实 XOR 严格下降、连续矢量与直接父序、数字区域唯一对应和邻接。
4. 固定工作量下相同输入产生相同合法起点。在某一共有状态上，条目由上述依赖保持有效，因此两侧生成同样的提案、顺序和接受结果。把这个结论沿已接受的操作递推，可得到相同的自然停止轮或第八轮，以及同一状态下的相同 PM31。有限截止时能完成的轮数需要单独实测，不由此递推确定。
5. 几何与几何加强方法共用原 `geometrySeed` 且每条调用独立求解。单纯几何种子返回后结束；几何加强在自己的合格种子上使用相同的圈内优化。

## 诊断接口

在同一次、固定输入的离线轨迹中，以 `cache=[]` 开始，逐轮调用 `[next,log,cache,trace]=efStep(prep,state,method,cache)`。生产仅请求前三个返回值。诊断仅保存实际使用的数据，不改变排序、预筛和验证过程。

| 字段 | 定义 |
|---|---|
| `donors`、`receivers` | 未做全局排序的所有单项。列分别为代价、环、顶点，及代价、环、边、插入 x、插入 y |
| `ringDenseIndices`、`donorDenseIndices`、`receiverDenseIndices` | 当前顶点及两张单项表相应点的原稠密环下标 |
| `ringVersion`、`rebuiltRings`、`reusedRings`、`invalidatedRings` | 当前轮版本、重建/复用的条目以及该轮接受后失效的条目。版本按某圈实际重建次数递增 |
| `lossByRing`、`baseAdditive` | 每圈当前孤环误差和该轮初始可加总和 |
| `pairs`、`eligible` | 全局前 24 完整排序矩阵与截断前全部合法组合数。矩阵列依次为代理和、供圈、供点、受圈、接收边及插入 x、y |
| `additive`、`rank` | 前 24 每个联合提案的实际可加误差，以及通过严格可加预筛后的验证顺序 |
| `checked`、`checkedXor`、`checkedReason` | 生产路径实际调用整图复验的候选序号、真实错分、复验理由。没有进入生产复验的提案可由审核程序另行完整重画 |

表内的 MATLAB 数组及候选编号从 1 开始。最终动作日志 `log` 沿用冻结实验的 0 基供受环和位置编号。实收时间由同步接收器进入后的第一条语句读取，打包和调用内缓存计算均包含在计时范围内。


## 第二轮触发前的预登记设计

参考开发剖析把单插和单删的累计时间分别定位为 32.975 s 和 22.590 s，总计覆盖此次 81.834 s 剖析中的 55.565 s。若第一轮无法达到事前工程门槛，第二轮只改这些单项的真实孤环评分。联合预筛继续调用原完整回填，正式接受继续重新渲染整图并执行全部结构验收。此节登记设计，实际实现与验证另行记录。

以一个原图像素中心为例，沿本行把原光栅器的所有定点交点横坐标从小到大排列。原算法把每对相邻交点之间的闭区间涂为前景，再涂八连通边线。记 P 为中心严格左侧交点数的奇偶。记 B 为该中心落在八连通边线上及恰与扫描交点重合的覆盖次数之和。则该像素的填充值精确等于 `P || B>0`。每一个扫描交点都是某个闭区间的端点；即使交点重合，只要中心与它重合，也须涂上。

在活动环上，单删替换原有两边为一边，单插替换一边为两边。每条未改边在新旧奇偶中的贡献完全相同。按原光栅器的定点斜率，在原图的全部有效行生成所有改边的交点，将旧边和新边的交点一起排序。旧环和新环在每个采样行的交点数均为偶数，共同边相消后仍为偶数。每对 c1、c2 之间奇偶翻转的列从 `floor(c1/262144)+1` 到 `floor(c2/262144)`，列索引只在原图有效范围截断。这里使用整幅原图上的行列，覆盖范围由离散交点逐行推得。

旧边和新边的八连通线迹及恰落在像素中心的交点分别以 −1、+1 更新 B。共享端点或多条线穿过同一中心时，按实际次数相加，不能把删除一条线解释为清除该点的所有覆盖。所有 P 翻转或 B 改变的位置构成需要复算的集合。未出现在集合中的中心两项均保持原值。用该集合上候选与活动蒙版的真实不同像素 T，可得错分数改变量 `nnz(T)-2*nnz(T & currentError)`。三角供点的单删代理最终只剩双点，正向和反向的闭合边均照原规则计入。

设计采用原尺寸离散边贡献计算，完整有序环的 B、P 仅在该圈重建代理时创建。候选编号附在线迹和交点上，多个单项可以批量排序与求和。若触达像素过多，按编辑分块，单个候选始终完整计算。逐项对照原画布、共端点重复线迹、水平边、恰在半格的斜边、三点删为二点及贴图边界，构成实施前已知的必要核对。


## 第二轮的实际接口和内存回退

第二轮沿用第一轮的 `efMeasure` 和 `efStep` 接口，第一轮原代码在 `performance/versions/v1`。本轮 `efCandidates` 仍按原顺序构造删点位置和插点坐标，把这一圈的所有单项一次交给 `efSingleChanges`。该函数建立本圈当前的原幅 P 及 B 并断言重建原活动图层完全相等。候选编号、原生行列和带符号的边覆盖在完整坐标系内计算。相同中心的多个事件按原幅线性索引与候选编号合并。最终仅缓存得分、环版本和源下标，临时的 P、B、翻转和事件数组在当前环单项得分完成后释放。

```matlab
[delta,flips,stats]=efSingleChanges(shape,points,currentMask,referenceMask,changes);
```

`changes` 一行对应 `[操作, 当前顶点或边的1基下标, x, y]`。操作 −1 删除顶点，坐标可填零；操作 +1 在所给边起点后插入坐标。第二返回值按编辑顺序提供每个真实翻转像素的原图 MATLAB 列优先线性下标，按升序存为列向量。无翻转时返回 0×1。生产传入第六参 `false` 关闭逐编辑翻转列表留存，增量计算本身仍执行。独立核对可对每个返回列表依次翻转当前图层，与原 `rasterRing` 对最终折线的完整回填逐像素比较。

两个内部工作量上限只控制临时存储与批处理。边事件估值阈值为 1,000,000，按边数与原图较大边长的乘积估计单组展开量；实际临时数组还包含坐标、所属编辑等字段。若当前活动环本身超过此估值，该圈全部单项回到原幅 `rasterRing`。一般情况下最多一次合并 `floor(1000000/(3*max(shape)))` 个编辑，至少一个，以限制三条改边形成的事件组。第二个上限为 500,000 个奇偶翻转列与带符号边界事件的合计条目，在建立合并键表前据实计算；单个编辑超过时仅这一项改用原幅完整回填，其余项按编辑分批。上限均为固定工作量保护值，没有按图像误差、用时或正式资料选择。回退同样从真实坐标计算完整错分，逐调用另记 `fastCounters.fallbackCalls`、`baseLimitFallbacks`、`editLimitFallbacks`。无回退数值为零。若数学分解与当前图层不等，程序报错并保留异常。

开发中单行图暴露了两项数组形状问题。无交点时的空标号输入使 MATLAB 的 `accumarray` 拒绝尺寸参数；仅有一个横向区间时，`repelem` 在某些输入上返回行向量，可能与列向量隐式扩展或无法拼接。逐编辑工作向量统一转列，无事件直接产生相应长度的全零计数。1×1 无翻转项另规范为 0×1 的下标列表。已从保存反例重新运行独立对抗夹具；附加合成检验覆盖 1×1、1×13、17×1、2×1、1×2 共 2,604 次单项翻转，并分别构造了触达两个回退分支的输入。
