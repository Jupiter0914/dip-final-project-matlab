# 数据与署名

- Oxford-IIIT Pet 由 O. M. Parkhi、A. Vedaldi、A. Zisserman 和 C. V. Jawahar 发布。实验使用官方 trimap 的索引值 1 作为前景。36 张开发标注属于 trainval，两次确认的 Oxford 名单单独登记。[数据主页与论文](https://www.robots.ox.ac.uk/~vgg/data/pets/)
- LEMS 形状来自 Costas Panagiotakis 在 Unconstrained Polygonal Fitting 项目中分发的 Datasets_LEMS_MPEG7 数据集。本实验在冻结清单中登记了 100 个 LEMS 形状。另有单外环的开发探索使用该作者发布的 MATLAB PSO 程序，原程序由作者分发。[作者资料与数据](https://sites.google.com/site/costaspanagiotakis/research/unconstrained-polygonal-fitting)
- PM31 的文件格式、坐标约定、光栅化规则和逐像素测试见[编解码验证](codec-validation.md)。
