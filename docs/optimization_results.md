# 精确评价加速实验结果

## 首轮按环缓存

在 36 个获准开发源上，三进程各两次，八个方法共 1,728 次独立编码，保存 10,776 次接收和 602 组不同源/字节文件。四种方法逐源的成功状态、自然停止、每次尝试、实际字节和真实 XOR 均按固定最多八轮核对。完整证据位于 perf_results/dev1。

跨圈总耗时的新/旧来源等权几何平均比为 0.96719，耗时下降 3.28%。三场各为 0.95554、0.97377、0.97236。36 源、216 对合法非空重复全部纳入；普通 95% 开发区间为 [0.94561, 0.98597]。首次跨圈文件的实收比为 0.99419，保护项最差比为 1.00665。第一候选未达到 0.90 的总耗时投入门槛。

同轮文件在开发固定工作量下，跨圈起点、第1轮、第2轮、第3轮的配对实收差中位数依次为 −0.255、−1.298、−2.908、−4.535 ms。后续轮只对双方实际完成的同轮文件比较。这里没有把运行八轮取得的文件倒算为100 ms及时交付。

首轮完整合成及开发轨迹的 2,348 个试探轮中复用 318 次不变环。多数单环源每次接受动作都会改变本环。缓存能省掉其他环的重复提案，其节省范围受环数和实际接受轨迹限制。原参考 Profiler 的 141,725 次 rasterRing 调用包含大量仍需重算的单项评价。第2轮按事前允许的最后一次优化，针对这个已记录的热点实施全局离散更新。

## 第二轮全图离散改边

第二候选仅改变单环单删插的精确评分。每次联合删插的最终可加重排、原尺寸整图降错、矢量和数字拓扑验收及同步交付仍调用对应参考规则。129,139 项单独编辑共 5,988,110 个翻转像素位置与完整回填逐一相同。独立重读的 2,978 次检查点涉及 1,640 份不同字节文件。在两类临时事件表上限下，开发轨迹回退 0 次，专门夹具另验证了全图回退。针对单行、单列出现的两处数组形状问题在工程计时之前修正，在同一套全部合成与开发输入上从头重验。

第二轮共 1,728 次工程调用、10,776 次接收。跨圈总耗时的几何平均新/旧比为 0.34388，对应耗时减少65.61%。三进程比为0.34409、0.34412、0.34344，保护项最差1.01596。26个单环源比值0.31692，10个多环源比值0.42522。跨圈初始文件未见系统性提前，216个配对的中位时移为 +0.146 ms；第1轮的216对全都更早，中位时移 −50.822 ms。在双方都完成第8轮的23源138对上，中位时移 −415.860 ms。以上均为固定工作量的开发测量。它们满足投入门槛，100 ms 的实际可用文件须用新样本的独立限时调用确定。

## 新确认的预定总体

从官方 test 的3,669个身份出发，历史筛查表覆盖3,705个Oxford输入，并联结372个已知派生视图。排除已用源、别名、同原文件/像素和已触及家族后，有3,064个合格家族代表。near、holes、components、simple 四层的合格代表分别为198、358、556、1,952。各层按预先指定摘要排序取50个，再用另一固定盐各取12个进入48源子集。200份原字节、行序像素和尺寸全部核过，输入为50单环、150多环。200源清单的规范 LF SHA-256 为 `82024d6eee995e7f230a8e0a785059fa30ef8e0639d3bdc579cf384bfb57ceaa`。

冻结提交 `c790f35de421be7c8231e35d8ca0bd2bf1d0fadb`，104项冻结摘要为 `6e0d88c77b59d557b0a6ac50893a75b72c5f013d713c7b4007a973685ab91be1`。每一计划方法位置都列在 performance/sampling/confirm_order.csv。新确认的质量只从独立限时调用的已收 PM31 计算。

## 正式确认 A · 同工作量加速

三个新单线程进程完成全部8,352次正式调用。48个固定工作量源均为双方有合法非空且工作内容与对应文件一致的输入，每个来源6对，共288对跨圈测量。fast_cross / old_cross 的总耗时比为 **0.36246**，普通95%区间 [0.34162, 0.38441]，双侧97.5%区间 [0.33835, 0.38798]，对应耗时降低 **63.75%**。12单环源的比值为0.30132，36多环源为0.38549。快版圈内相对旧圈内为0.34338，双侧97.5%区间 [0.32333, 0.36491]。预登记的主要性能主张得到支持。

固定工作量下跨圈首份文件实收比为1.00065，双侧97.5%区间 [0.99310, 1.00811]。初始求解没有采用新评分。第1、第2轮相同字节在各288个同轮配对中的实际接收时差中位分别为 −38.12 和 −76.88 ms；共同到达第8轮的120对为 −276.60 ms。每轮分母、耗时比、实收和间隔在 perf_results/output/fixed_checkpoint_ratios.csv 与 fixed_common_receipts.csv。内存数据为调用边界的进程快照，见 fixed_memory.csv。

## 正式确认 B · 相同加速条件下的跨圈增量

新 Oxford 多环、256 B、100 ms，fast_within 错分减 fast_cross 错分为 **−0.99111 像素**，95%区间 [−2.71444, 0.66000]，双侧97.5%区间 [−2.99222, 0.86944]。150个共同源、881对及时同码长文件，中位数0，48胜、32平、70负。三会话均值 −1.8154、−1.0467、−0.1259。留一源均值范围 [−1.1544, −0.5224]；六次全部共同成功的141源均值 −1.0437。全部200源上，快跨圈减快圈内交付差 −0.250 个百分点，95%区间 [−0.750, +0.167]，符合 −2 个百分点相对容忍条件。主效应区间与方向未满足稳定性条件，100 ms 跨圈增量未得到支持。200 ms 预登记补充为150源898对，+10.11222像素，普通95%区间 [6.56000, 14.12056]。

## 交付复核

正式测量时的41份参考源码通过了逐文件摘要核验，参考命名空间适配改动为零。旧300的1200个固定工作量调用含1122成功、78个有限池无合法输出，两侧状态及原因相同。6128轮、147072个入选候选、877479个单项评分、50193417个翻转像素位置均一致。6891次实际检查点用4910份不同PM31复读，5769个动作逐顶点复核，其中293个跨圈。此证据只涵盖这些输入、预算、实现及可执行轨迹。

三场正式 MATLAB 进程的 PID 为55464、51672、46924，均使用单线程。固定网格有8112次接收，限时网格有36027次接收。独立 MATLAB 审计直接从原始 JSONL 与869组主终点相关源/文件恢复A、B及普通和调整区间，14个核验字段的最大绝对差为4.45×10⁻¹⁵以内。4类正式实验图及流程图均有可编辑SVG和约320 dpi PNG，额外保留开发等价/会话图。在改善、持平、退化案例中，6份实际文件及其每一处FP/FN像素与图相符。
