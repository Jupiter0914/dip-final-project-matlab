# 分析与抽样预检

MATLAB R2024a 单线程批处理实际执行 `perfAnalysis(pwd,'test')`，正常退出。测试只读36个获准的官方 trainval 开发源并使用独立临时合成夹具。36个源的原生结构分层与历史输入描述逐项一致。

临时夹具包含两个独立标识和真实生成、解码的二部件 PM31，用显式给定时刻测试截止判断。六种方法、三会话、两重复共72个模拟调用，在100和200 ms产生144行单元测试观察。100.0 ms按时，100.1 ms晚到。该项给定的文件对在100 ms有11/12次同时符合条件，六次全部成功的来源有1个，四方同长交集也为11。给定的总时长比0.8在源级聚合后保持0.8。受检数据令A通过、B不通过，和独立手算的结果一致。临时文件已清理。这些时钟值用于测试观察规则，未写入开发计时、正式样本或任何性能估计。

第一轮开发图使用真实开发计时、逐轮验证和实际两套剖析产物。三幅输出已核验横纵分辨率、SVG可见矢量并目检。第一轮的独立快照在 `perf_results/output/development/dev1/`。

在正式冻结前增加人可读的判据摘要时，MATLAB 的字符型格式模板让 compose 返回单元格文本，直接用 sprintf 写入会话均值会报类型错误。改用字符串格式并将最终串转为字符向量，保留全部数值逻辑和原断言，使用同一合成夹具重查。

正式冻结前又执行 `perfAnalysis(pwd,'testFigures')`。它在临时目录用前述两张合成图、实际PM31和已知边界测量测试量运行固定时间、四格配对、A/B判定、案例解码、全部四幅正式绘图分支及SVG/双向分辨率校验。低于0.0001 ms的正时长被单列排除，固定总时长比与质量判据保持预期。该次批处理连同真实抽样、独立名册审计及第二轮开发图复核均正常退出。
